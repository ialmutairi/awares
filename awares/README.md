# awares — الوعي والامتثال التنظيمي

أداة مجانية للمنشآت السعودية، بوضعين:

1. **حلّل منشأتي** — اوصف منشأتك، فيبني لك النموذج **استبياناً مفصّلاً على نشاطك أنت**، ثم يبحث في المصادر الرسمية ويعيد: الأنظمة المنطبقة، والمخالفة التي قد تقع فيها (بصياغتها النظامية **وبلغة مبسّطة**)، والغرامة، وخطوات الاستيفاء، ورابط المصدر.
2. **التغطية** — أي قطاع نغطّيه، وكم جهة رقابية في كل قطاع، وما نطاقاتها الرسمية. عرض ثابت: **صفر استدعاءات، صفر تكلفة**.

---

## سجل الجهات — الأهم في المشروع

`regulators.mjs` يحوي **٤٥ جهة رقابية** و**٤ مصادر مرجعية عليا**، وكل نطاق فيه **جرى فحصه حياً** (طلب HTTP + سجل DNS).

هذا ليس تفصيلاً شكلياً. أول فحص أسقط أربعة نطاقات كانت «معروفة» وهي ميتة تماماً:

| كان في الذاكرة | الصحيح | الحالة |
|---|---|---|
| `cchi.gov.sa` | `chi.gov.sa` | لا سجل DNS للأول |
| `gcam.gov.sa` | `gmedia.gov.sa` | لا سجل DNS للأول |
| `gastat.gov.sa` | `stats.gov.sa` | لا سجل DNS للأول |
| `wera.gov.sa` | `swa.gov.sa` | لا سجل DNS للأول |

وثلاث جهات غيّرت نطاقها بعد الدمج أو إعادة التسمية: `cma.org.sa → cma.gov.sa`، و`momra → momah`، و`citc → cst`.

**الدرس المعماري:** أي نطاق يأتي من ذاكرة نموذج لغوي احتمال خطئه معتبر. لذلك:
- السجل مكتوب يدوياً ومُتحقَّق منه، لا مولّد.
- `officialSource()` ترفض أي رابط لا ينتمي لهذا السجل أو لـ `*.gov.sa`.
- كل بند يُعرض عليه وسم إن كان مصدره لم يظهر في نتائج بحث النموذج الفعلية.

إعادة الفحص:

```bash
node verify-regulators.mjs          # ٤٩/٤٩ سليم حالياً
node verify-regulators.mjs --json
```

يستخدم `fetch` ثم يسقط إلى `curl` — لأن بصمة TLS الخاصة بـ Node تُحجب في جدران حماية عدة مواقع حكومية، فيفشل `fetch` حيث ينجح `curl`. بدون هذا الاحتياطي يُبلَّغ عن ست جهات حيّة كأنها ميتة.

**شغّله كل بضعة أشهر.** الجهات السعودية تُدمج وتُعاد تسميتها باستمرار.

## المزودون

يعمل بأي من هذه المفاتيح، ويكفي واحد:

| المزود | المتغيّر | النموذج | البحث الحيّ |
|---|---|---|---|
| xAI | `XAI_API_KEY` | `grok-4` | Agent Tools API (`/v1/responses`) |
| Google | `GEMINI_API_KEY` | `gemini-2.5-flash` | Google Search grounding |
| Anthropic | `ANTHROPIC_API_KEY` | `claude-sonnet-4-5` | web_search |

وجود أكثر من مفتاح يفعّل **التحقق المتقاطع** في `refresh.mjs`: يُسأل كل نموذج على حدة وتُدمج النتائج. ما يتفق عليه نموذجان يُوسم «مؤكّد»، وما ينفرد به واحد يُوسم بوضوح — أرخص طريقة لكشف الغرامات المخترعة.

لإضافة مزود رابع: أضف كائناً في `providers.mjs`. لا شيء آخر يحتاج تعديلاً.

## الذاكرة وخفض التكلفة

`cache.mjs` يحفظ نتائج الاستبيان والتحليل بمفتاح مبنيّ على **وصف مُطبَّع** لا على النص الحرفي، فيلتقي «مقهى بفرعين ١٢ موظف» مع «مقهى، فرعين، 12 موظفاً» على نفس المدخل.

- الاستبيان: يُحفظ شهراً
- التحليل: يُحفظ أسبوعاً
- في Cloudflare يستخدم `caches.default`؛ محلياً `Map` في الذاكرة

القياس الفعلي: استدعاء بارد ١٨ ثانية، والمكرر **صفر ثانية وصفر تكلفة**.

> تنبيه للمطوّر: التطبيع يحوّل الأرقام الهندية قبل حذف التشكيل عمداً. كتابة نطاق التشكيل بالشكل `[ً-ٰ]` تعني `U+064B..U+0670` وهي **تبتلع الأرقام الهندية** `U+0660..U+0669`، فينكسر تطابق الذاكرة بصمت. النطاق مكتوب برموز صريحة في `cache.mjs` و`analysis.mjs`.

## المستجدات التنظيمية

```bash
npm run news              # نافذة ٤٥ يوماً
node news.mjs --days 60
```

يرصد ما **تغيّر** لدى ٩ مجموعات تنظيمية: نظام صدر، لائحة عُدّلت، جدول مخالفات نُشر، مشروع على استطلاع، حملة ضبط. يكتب `public/data/news.json` فتقرأه الواجهة كملف ثابت — **تكلفة العرض صفر**.

خبر بلا مصدر رسمي **لا يُنشر** — الخبر بلا مرجع إشاعة. يعمل مجدولاً كل اثنين عبر `.github/workflows/news.yml`.

## مشاركة المستخدمين

**اقتراح مصادر** — في تبويب «التغطية»، يقترح المستخدم رابطاً لقطاعه. سلسلة الفحص في `sources.mjs` ترفض: غير الرسمي، والنطاق المنتحل، والصفحة الرئيسية بلا مستند، والرابط الميت (٤٠٤)، والمكرر.

> **المقترحات لا تدخل السجل المُتحقَّق منه ولا تُمرَّر للنموذج كمرجع.** تُعرض موسومة «مقترح — غير مراجَع»، والترقية تحتاج مراجعة بشرية. أداة امتثال تعرض رابطاً أضافه مجهول وكأنه مرجع رسمي = ضرر مباشر على من يصدّقه.

**التقييم** — يُسأل بعد رؤية النتيجة لا قبلها. المتوسط يظهر للعموم في لوحة الجودة، ورسائل المستخدمين تظهر في شريط أفقي **بما فيها الانتقادات**. الرسائل تُنظَّف على الخادم (حذف الروابط وأرقام التواصل ووسوم HTML) — وهي ليست فلترة محتوى كاملة، فراجعها إن كبر الاستخدام.

## قياس جودة النتائج

```bash
npm run eval          # ٥ منشآت نموذجية
node eval.mjs --quick # ملفان فقط
```

يشغّل ملفات منشآت عبر المسار الكامل، ويقيس ما **يمكن التحقق منه آلياً**، ثم يكتب `public/data/quality.json` فتعرضه الواجهة **للعموم** في تبويب «التغطية».

آخر قياس — ٥ منشآت، ٢٠ بنداً:

| المقياس | النتيجة |
|---|---|
| مصدر رسمي | ١٠٠٪ |
| الرابط يفتح فعلاً | ٩٥٪ |
| **جزاء محدد بالريال** | **٥٥٪** ← الأضعف |
| شرح مبسّط للمخالفة | ١٠٠٪ |
| مربوط بنشاطك | ١٠٠٪ |
| موسوم للمراجعة | ٥٪ |

**حدّ هذا القياس، بصراحة:** يقيس *شكل* المخرجات لا *صحة أرقامها*. أن يفتح الرابط لا يعني أن الغرامة صحيحة. هذا يحتاج مراجعة بشرية، والواجهة تقول ذلك حرفياً بدل إخفائه.

نعرض الأرقام حتى لو ساءت — أداة امتثال تخفي معدّل خطئها أسوأ من أداة لا تقيسه أصلاً.

## التشغيل محلياً

```bash
npm install
cp .env.example .env      # ثم ضع مفاتيحك
npm run dev
```

تبويب «التغطية» يعمل بلا مفاتيح. تبويب «حلّل منشأتي» يحتاج مفتاحاً واحداً على الأقل.

المفاتيح تُقرأ من `.env` على الخادم فقط ولا تصل حزمة المتصفح. للتأكد بعد أي تعديل:

```bash
npm run build && grep -rE "xai-|sk-ant-|AIza" dist/ && echo "تسريب!" || echo "نظيف"
```

## البنية

| الملف | مسؤوليته |
|---|---|
| `regulators.mjs` | سجل الجهات ونطاقاتها المُتحقَّق منها. مصدر الحقيقة للتغطية وللتحقق من الروابط. |
| `verify-regulators.mjs` | يفحص السجل حياً ويقول أيّ نطاق مات أو تحوّل. |
| `providers.mjs` | واجهة واحدة فوق المزودين. بلا استيراد من Node، فيعمل في Node وفي Cloudflare Workers. |
| `analysis.mjs` | الصياغات، واستخراج JSON، والتحقق من المخرجات، والدمج المتقاطع. |
| `cache.mjs` | ذاكرة النتائج والتطبيع العربي. |
| `api-core.mjs` | منطق `/api/intake` و`/api/analyze` — مشترك بين الإنتاج والتطوير. |
| `functions/api/*.js` | دوال Cloudflare Pages (الإنتاج). |
| `dev-api.mjs` | نفس الدوال كوسيط داخل Vite (التطوير). |
| `sectors.mjs` | تعريف القطاعات. |
| `refresh.mjs` | **اختياري** — توليد بيانات قطاعية تُستخدم كسياق مُثبت للتحليل. |

`refresh.mjs` لم يعد شرطاً للتشغيل. الواجهة لا تقرأ `public/data` إطلاقاً؛ يقرأها `/api/analyze` فقط كسياق إضافي إن وُجدت. اتركه معطّلاً لتخفيض التكلفة، أو شغّله لقطاعاتك الأهم.

```bash
node refresh.mjs food            # قطاع واحد
node refresh.mjs --solo food     # مزود واحد — أرخص وأسرع
```

## النشر

### ١. ادفع على GitHub

```bash
git init && git add . && git commit -m "awares"
git remote add origin git@github.com:<حسابك>/awares.git
git push -u origin main
```

تأكد أن `.env` **ليس** ضمن ما دُفع — هو في `.gitignore` أصلاً.

### ٢. أضف المفاتيح

**Cloudflare Pages** → Settings → Environment variables: `XAI_API_KEY` و/أو `GEMINI_API_KEY`.
بدونها يختفي تبويب «حلّل منشأتي» تلقائياً ويبقى تبويب «التغطية» شغّالاً.

لو فعّلت `refresh.mjs`: أضف نفس الأسماء في المستودع → Settings → Secrets → Actions.

### ٣. اربط الاستضافة

Create project → Connect to Git → اختر المستودع
- Build command: `npm run build`
- Output directory: `dist`

مجلد `functions/` يُلتقط تلقائياً فتصبح `/api/*` متاحة. للتخزين الدائم (المصادر والتقييمات) اربط KV باسم **`AWARES_KV`** — بدونه تعمل على ذاكرة العملية وتضيع عند إعادة النشر.

## البديل: GitHub Pages

**اقرأ هذا قبل أن تجرّب.** GitHub Pages استضافة ثابتة **لا تشغّل خادماً**. النتيجة:

| التبويب | على GitHub Pages |
|---|---|
| المستجدات | ✅ يعمل كاملاً (ملف ثابت) |
| التغطية | ✅ يعمل كاملاً |
| **حلّل منشأتي** | ❌ **لا يعمل** بلا خادم |

السبب: التحليل يحتاج مفاتيح Grok/Gemini، ومفتاح في المتصفح مفتاح مسروق. لا مفرّ من خادم يحملها.

**الحل المجاني:** انشر الواجهة على Pages، وضع `/api` في **Cloudflare Worker** منفصل (مجاني، بلا بطاقة)، ثم اضبط في المستودع → Settings → Variables:

```
VITE_BASE      = /<اسم-المستودع>/
VITE_API_BASE  = https://<worker>.workers.dev
```

`.github/workflows/pages.yml` جاهز، ويفشل البناء إن تسرّب مفتاح إلى الحزمة.

### Firebase بدل Worker؟

- **Firestore على خطة Spark مجاني** ويصلح لتخزين المصادر والتقييمات مباشرة من المتصفح. اضبط `VITE_FIREBASE_PROJECT` و`VITE_FIREBASE_KEY`، وانشر `firestore.rules` (القواعد هي الحارس الوحيد — المتصفح لا يُؤتمن).
- **دوال Firebase تتطلب خطة Blaze ببطاقة ائتمانية**، فلا تحلّ مشكلة التحليل مجاناً.
- قيد صادق: في هذا المسار **يسقط فحص حياة الرابط** عند اقتراح مصدر، لأن CORS يمنع المتصفح من قراءة رد `gov.sa`. تبقى فحوص الشكل والنطاق والتكرار.

**التوصية:** Cloudflare Pages وحدها تفعل كل شيء مجاناً وبلا هذا التعقيد.

### ٤. ضع حداً للاستهلاك

التحليل الفوري هو البند الوحيد الذي ينمو مع عدد الزوار. أضف قاعدة **Rate Limiting** في Cloudflare على `/api/*` قبل الإطلاق — الذاكرة تخفّف الأثر لكنها لا تمنع زائراً يغيّر الوصف كل مرة.

## الحمايات المدمجة

| الحماية | ماذا تفعل |
|---|---|
| سجل نطاقات مُتحقَّق منه | المصادر تُقاس على `regulators.mjs` المفحوص حياً، لا على ذاكرة النموذج |
| فلترة المصادر | يُتحقق من **مضيف** الرابط عبر `URL` لا بمطابقة نصية — فلا يمرّ `evil.com/x.gov.sa/` |
| وسم المصدر غير المتحقق | إن ادّعى النموذج مصدراً لم يظهر في نتائج بحثه الفعلية، يُعرض تنبيه |
| التحقق المتقاطع | بند يذكره نموذجان يُوسم «مؤكّد»؛ المنفرد يُوسم بوضوح |
| منع اختراع الغرامات | التعليمات تمنعه صراحة، والحقل يعود «غير محدد في المصدر» بدل رقم مخترع |
| صياغة مزدوجة للمخالفة | النص النظامي كما ورد، وتحته شرح بلغة صاحب المنشأة — بلا تحريف الأصل |
| سقوف المدخلات | حد لطول الوصف والإجابات وحجم الطلب |
| إعادة المحاولة | ٣ محاولات بتباعد تصاعدي، ومهلة زمنية تمنع التعليق |

## قبل الإطلاق

1. `node verify-regulators.mjs` — يجب أن يمرّ كاملاً.
2. راجع أول مخرجات بنفسك بنداً بنداً. افتح مصدر كل بند فيه غرامة وتأكد منه.
3. ابدأ بالبنود الموسومة «مصدر تحليل واحد» — هي الأرجح خطأً.
4. أضف طريقة للتبليغ عن خطأ. البلاغات أنفع مصدر لتحسين الأداة وأرخص من أي مراجعة مدفوعة.

## تنبيه

المحتوى **استرشادي** وليس شهادة امتثال ولا استشارة قانونية. يُجمَع آلياً من مصادر منشورة وقد يحتوي أخطاء أو يتأخر عن آخر تحديث رسمي. التحقق من المصدر الرسمي مسؤولية المستخدم.
